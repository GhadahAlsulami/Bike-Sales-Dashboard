# 🚴‍♂️ Bike Sales Dashboard  
**Analyzing Customer Demographics & Sales Trends**  

## 🔍 Project Overview  
This project presents a **Bike Sales Dashboard**, built using **Microsoft Excel**, to analyze key factors influencing bike purchases. The dashboard provides insights into:  
✔ **Customer income levels and purchase decisions**  
✔ **Age groups most likely to purchase bikes**  
✔ **Impact of commute distance on purchasing behavior**  
✔ **Regional and educational factors affecting bike sales**  

The dashboard helps businesses and marketers **understand customer purchasing patterns** and **identify target demographics**.  

## 🛠 Tools & Technologies Used  
- 📊 **Microsoft Excel** – Data analysis and dashboard creation  
- 🔄 **Pivot Tables** – Summarizing and analyzing customer purchase data  
- 📉 **Pivot Charts** – Visualizing insights dynamically  
- 🎛 **Slicers & Filters** – Enhancing user interactivity for data exploration  

## 📊 Key Insights & Features  
📍 **Higher income levels correlate with increased bike purchases**, especially among males.  
📊 **Middle-aged customers** are the most active buyers, while adolescents show the lowest purchase rates.  
🚲 **Customers with shorter commute distances (0-1 miles) are more likely to buy bikes** compared to those with longer commutes.  
🌍 **Regional differences impact purchasing behavior**, with some areas showing higher interest in biking.
